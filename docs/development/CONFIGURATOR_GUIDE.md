## Что такое Конфигуратор

Конфигуратор — это раздел платформы, позволяющий адаптировать модель Trust Score под специфику вашей организации.

Каждая организация уникальна: банк больше обеспокоен соответствием требованиям регуляторов, производственное предприятие — уязвимостями АСУ ТП, IT-компания — управлением доступом. Конфигуратор позволяет отразить эти приоритеты, изменив веса факторов модели доверия.

**Доступ:** Владелец (owner) и Аналитик ИБ (analyst).  
**Маршрут:** `/configurator`

---

## Как работает модель Trust Score

Trust Score каждого объекта рассчитывается по формуле (ADR-001):

```
Trust Score = Σ (оценка_фактора × вес_фактора) / 100
```

Платформа оценивает 6 независимых факторов безопасности:

| Фактор | Что измеряет | Вес по умолчанию |
|---|---|---|
| Уязвимости | Число и критичность известных CVE и уязвимостей | 22% |
| Конфигурация | Соответствие стандартам безопасной конфигурации | 18% |
| Доступы | Управление привилегиями и учётными записями | 18% |
| Сегментация сети | Изоляция и контроль сетевого трафика | 14% |
| Соответствие ПБ | Выполнение политик безопасности и требований | 16% |
| Инциденты | История инцидентов и время реакции | 12% |

Каждый фактор получает оценку от 0 до 100 на основе данных об объекте (критичность, риски, полнота паспорта).

**Итоговый Trust Score** = взвешенная сумма факторных оценок.

---

## Что означают веса

Вес фактора определяет, насколько сильно этот аспект влияет на итоговый Trust Score.

**Пример:**

Объект имеет критическую уязвимость (оценка фактора «Уязвимости» = 30) и нормальную конфигурацию (оценка «Конфигурация» = 80).

*С весами по умолчанию:*
```
Trust Score ≈ 30 × 0.22 + 80 × 0.18 + ... = 6.6 + 14.4 + ... 
```

*Если банк увеличит вес «Соответствие ПБ» до 30%:*
- Изменения в соответствии требованиям будут сильнее влиять на итоговый Score
- Объект с хорошим compliance получит бонус, с плохим — больший штраф

---

## Правила настройки

1. **Сумма всех весов = 100%** — обязательное условие. Кнопка «Сохранить» заблокирована, пока сумма не равна 100.

2. **Каждый вес — целое число от 0 до 100.** Дробные значения не допускаются.

3. **Вес может быть 0%** — это означает, что данный фактор полностью исключён из расчёта для вашей организации.

4. **Изменение весов запускает массовый пересчёт** Trust Score всех объектов организации. После сохранения вы увидите обновлённые оценки во всех паспортах и на Dashboard.

## Как изменить веса

### Шаг 1: Откройте Конфигуратор

Перейдите в `/configurator` через навигацию платформы.

### Шаг 2: Настройте слайдеры

Для каждого фактора доступны:
- **Слайдер** — перетащите ползунок
- **Числовое поле** — введите значение вручную (0–100)

### Шаг 3: Следите за суммой

Внизу формы отображается счётчик суммы:
- **Σ = 100 ✓** (зелёный) — сумма корректна, можно сохранять
- **Σ = 108 ≠ 100** (красный) + подсказка — необходимо скорректировать веса

Если сумма не равна 100, платформа подскажет, сколько процентов нужно добавить или убрать.

### Шаг 4: Сохраните настройки

Нажмите **«Сохранить и пересчитать»**.

Платформа:
1. Сохраняет новые веса в базе данных
2. Пересчитывает Trust Score всех активных объектов организации
3. Обновляет организационный индекс доверия
4. Фиксирует событие в журнале аудита (для Владельца и Администратора)

После успешного сохранения появится сообщение: *«Сохранено. Все объекты пересчитаны.»*

## Сброс к значениям по умолчанию

Кнопка **«Сбросить по умолчанию»** восстанавливает исходные веса:
- Уязвимости: 22%
- Конфигурация: 18%
- Доступы: 18%
- Сегментация: 14%
- Соответствие ПБ: 16%
- Инциденты: 12%

Сброс является деструктивным действием и требует **подтверждения**:
1. Нажмите «Сбросить по умолчанию»
2. Появятся кнопки «Подтвердить сброс» и «Отмена»
3. Нажмите «Подтвердить сброс» для выполнения

Сброс меняет только локальное состояние формы — пока не нажата кнопка «Сохранить и пересчитать», изменения не применяются.

## Некорректные конфигурации

### ❌ Сумма ≠ 100%

```
Уязвимости:  30%
Конфигурация: 18%
Доступы:      18%
Сегментация:  14%
Соответствие: 16%
Инциденты:    12%
─────────────────
Сумма:       108% ← ОШИБКА
```

Кнопка «Сохранить» заблокирована. Платформа подскажет: «Уменьшите веса ещё на 8%».

### ❌ Дробное значение

Нельзя установить 22.5% — используйте целые числа. Если нужно перераспределить нечётное количество процентов, скорректируйте несколько факторов.

### ⚠️ Нулевой вес — допустимо, но с осторожностью

Вес 0% полностью исключает фактор из расчёта. Если организация не ведёт учёт инцидентов, вес «Инциденты» = 0% — разумное решение. Но убедитесь, что сумма остаётся = 100%, перераспределив эти проценты между другими факторами.

## Влияние конфигурации на аудит

Каждое сохранение весов фиксируется в журнале безопасности (`/settings` → «Журнал аудита»):
- Тип события: `config.weights_changed`
- Значения ДО изменения
- Значения ПОСЛЕ изменения
- Кто и когда изменил

Это позволяет расследовать изменения модели доверия при необходимости аудита.
