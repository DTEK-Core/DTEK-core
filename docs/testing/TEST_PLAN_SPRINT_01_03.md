## Модуль 1: Аутентификация

### TC-AUTH-001 — Регистрация нового пользователя
**Цель:** Создать новый аккаунт и попасть в онбординг  
**Шаги:**
1. Открыть http://localhost:3000
2. Если пользователь не вошёл — откроется лендинг
3. Нажать «Запросить доступ» или перейти на /register
4. Заполнить поля: Имя, Фамилия, Email, Пароль (мин. 6 символов)
5. Нажать «Создать аккаунт»

**Ожидаемый результат:** Перенаправление на /onboarding/create  
**Статус:** ⬜ PASS / FAIL

**Статус:** ⬜ PASS / FAIL

### TC-RISK-002 — Фильтрация по серьёзности
**Цель:** Фильтровать риски кликом по карточке  
**Шаги:**
1. На /risks нажать карточку «Критические»
2. Карточка подсвечивается
3. Таблица показывает только критические риски
4. Нажать карточку повторно — фильтр снимается

**Ожидаемый результат:** Фильтрация работает корректно в обе стороны  
**Статус:** ⬜ PASS / FAIL

### TC-RISK-003 — Поиск и фильтр по статусу
**Цель:** Проверить текстовый поиск и выпадающий фильтр статуса  
**Шаги:**
1. Ввести часть названия риска в поле поиска
2. Использовать выпадающий список «Статус» → выбрать «Открыт»

**Ожидаемый результат:** Список фильтруется по обоим критериям одновременно  
**Статус:** ⬜ PASS / FAIL

---

### TC-RISK-004 — Risk Drawer (просмотр деталей)
**Цель:** Открыть риск и проверить drawer  
**Шаги:**
1. Нажать на строку риска в таблице
2. Справа появляется Risk Drawer
3. Проверить: заголовок, CVSS-оценка с метром, мета-факты (Объект, Категория, Статус, Владелец, Возраст, SLA)
4. Нажать крестик или кликнуть по overlay — drawer закрывается

**Ожидаемый результат:** Drawer открывается/закрывается корректно, показывает данные риска  
**Статус:** ⬜ PASS / FAIL

---

### TC-RISK-005 — Изменение статуса риска
**Цель:** Перевести риск по жизненному циклу  
**Шаги:**
1. Открыть Risk Drawer для риска со статусом «Открыт»
2. Нажать «Взять в работу»
3. Статус меняется на «В работе»
4. Нажать «Устранить»
5. Статус меняется на «Устранён»

**Ожидаемый результат:** Статус обновляется в реальном времени (без перезагрузки страницы)  
**Статус:** ⬜ PASS / FAIL

---

### TC-RISK-006 — Создание риска
**Цель:** Зарегистрировать новый риск  
**Шаги:**
1. Нажать «Зарегистрировать риск» (кнопка в правом верхнем углу)
2. Заполнить: Название (обязательное), Категория, Серьёзность
3. Опционально: CVSS Score, Привязать к объекту, SLA (дней)
4. Нажать «Создать риск»

**Ожидаемый результат:** Риск появляется в таблице, диалог закрывается  
**Статус:** ⬜ PASS / FAIL

---

### TC-RISK-007 — Привязка риска к объекту через Drawer
**Цель:** Привязать риск без объекта к объекту  
**Шаги:**
1. Открыть Risk Drawer для риска, у которого нет привязанного объекта
2. Нажать «Привязать к объекту»
3. Выбрать объект из выпадающего списка
4. Нажать «Привязать»

**Ожидаемый результат:** В колонке «Объект» таблицы и в Drawer появляется название объекта  
**Статус:** ⬜ PASS / FAIL

---

### TC-RISK-008 — Редактирование и удаление риска
**Цель:** Изменить и удалить риск  
**Шаги:**
1. Нажать иконку редактирования риска
2. Изменить название
3. Нажать «Сохранить»
4. Открыть форму повторно, нажать «Удалить»
5. Подтвердить удаление

**Ожидаемый результат:** Изменения сохраняются; при удалении риск исчезает из таблицы  
**Статус:** ⬜ PASS / FAIL
