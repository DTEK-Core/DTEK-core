### TC-AUTH-P01 — Регистрация нового пользователя
**Цель:** Создать новый аккаунт и попасть в онбординг  
**Предусловие:** Браузер в режиме инкогнито  
**Шаги:**
1. Открыть http://localhost:3000
2. Нажать «Запросить доступ» → /register
3. Заполнить: Имя=`Тест`, Фамилия=`Пользователь`, Email=`test-{дата}@example.com`, Пароль=`TestPass123!`
4. Нажать «Создать аккаунт»

**Ожидаемый результат:** Перенаправление на /onboarding/create; профиль создан в таблице `profiles`  
**Статус:** ⬜ PASS / FAIL
