## Зачем нужен Конфигуратор

По умолчанию Trust Score рассчитывается с одинаковыми весами для всех организаций. Но разные организации имеют разные приоритеты безопасности:

- **Банк** критически зависит от соответствия регуляторным требованиям (compliance) и контроля доступа (access)
- **Производственное предприятие** с АСУ ТП больше рискует из-за неуправляемых уязвимостей (vuln) и сетевых угроз (network)
- **IT-компания** равномерно распределяет риски между всеми факторами
- **Медицинская организация** критически зависит от соответствия (compliance) и защиты доступа к персональным данным (access)

**Конфигуратор** позволяет изменить веса шести факторов Trust Score, адаптировав модель под реальные приоритеты вашей организации.

---

## Шесть факторов и их значение

| Фактор | Ключ | Вес по умолчанию | Что повышение веса означает |
|---|---|---|---|
| Уязвимости | `vuln` | **22%** | Уязвимости влияют сильнее на Trust Score |
| Конфигурация | `config` | **18%** | Неправильные настройки критичнее |
| Доступы | `access` | **18%** | Управление привилегиями важнее |
| Сегментация сети | `network` | **14%** | Сетевая изоляция важнее |
| Соответствие ПБ | `compliance` | **16%** | Соответствие политикам критичнее |
| Инциденты | `incident` | **12%** | История инцидентов влияет сильнее |

---

## Правила настройки весов

**Единственное ограничение:** сумма всех шести весов должна равняться ровно **100%**.

Платформа показывает текущую сумму в реальном времени при редактировании. Кнопка «Сохранить» становится активной только когда сумма = 100.

**Ограничения:**
- Минимальный вес одного фактора: **1%** (фактор нельзя обнулить)
- Максимальный вес одного фактора: **практически до 99%** (хотя это нецелесообразно)
- Дробные значения поддерживаются (например, 22.5%)

---

## Как изменить веса

1. Откройте `/configurator`
2. Измените значения в слайдерах или полях ввода
3. Следите за индикатором суммы (должна быть ровно 100%)
4. Нажмите «Сохранить»
5. Система запустит **пересчёт Trust Score всех объектов организации**
6. После завершения пересчёта вы получите уведомление

**Сброс к умолчанию:** кнопка «Сбросить» (двойное подтверждение) возвращает все веса к заводским значениям (vuln 22%, config 18%, access 18%, network 14%, compliance 16%, incident 12%).

---

## Как изменение весов влияет на расчёты

Изменение веса не меняет **оценки факторов** (они зависят от рисков и полноты паспорта). Оно меняет **итоговую формулу**:

```
Trust Score = (
    vuln_score       × NEW_vuln_weight +
    config_score     × NEW_config_weight +
    access_score     × NEW_access_weight +
    network_score    × NEW_network_weight +
    compliance_score × NEW_compliance_weight +
    incident_score   × NEW_incident_weight
) / 100
```

**Практический эффект:**
- Если повысить вес `compliance` с 16% до 30%, объекты с хорошей документацией (высокий compliance_score) вырастут в Trust Score
- Если повысить вес `vuln` с 22% до 40%, объекты с открытыми уязвимостями потеряют больше баллов

## Пример: эффект изменения весов

**Объект:** Сервер баз данных с одним средним риском (compliance category)

**Факторные оценки (не меняются):**
```
vuln = 75, config = 75, access = 75, network = 75, compliance = 60, incident = 75
```

**При стандартных весах:**
```
Trust Score = (75×22 + 75×18 + 75×18 + 75×14 + 60×16 + 75×12) / 100
            = (1650 + 1350 + 1350 + 1050 + 960 + 900) / 100
            = 7260 / 100 = 73
```

**После увеличения compliance до 30% (сокращены vuln до 18%, network до 10%):**
```
Trust Score = (75×18 + 75×18 + 75×18 + 75×10 + 60×30 + 75×6) / 100
            = (1350 + 1350 + 1350 + 750 + 1800 + 450) / 100
            = 7050 / 100 = 71
```

Trust Score снизился с 73 до 71, потому что теперь слабый compliance-фактор (60) имеет больший вес в итоговой оценке.

## Частые вопросы о Конфигураторе

**Вопрос:** Почему нельзя установить вес 0%?  
**Ответ:** Полное обнуление фактора означает, что целый аспект безопасности (например, уязвимости) перестанет учитываться совсем. Это создаёт искажённую картину и может ввести в заблуждение. Минимальный вес — 1%.

**Вопрос:** Сколько времени занимает пересчёт всех объектов?  
**Ответ:** Зависит от количества объектов. Для 10–50 объектов — несколько секунд. Для 100+ объектов — до минуты. Платформа уведомит о завершении.

**Вопрос:** Можно ли настраивать веса по-разному для разных объектов?  
**Ответ:** Нет — в текущей версии MVP настройки применяются ко всей организации. Это позволяет сравнивать объекты в одной шкале. Поддержка профилей по типам объектов запланирована на будущие версии.

**Вопрос:** Влияют ли изменения весов на историю Trust Score?  
**Ответ:** Нет. История сохраняется как есть. Каждый пересчёт добавляет новую запись в историю с причиной «weights_changed».
