# DTEK Core — Отчёты и экспорт

`Версия: 1.0`  
`Дата: 12.07.2026`  
`Актуально для: Sprint 10 — Reporting & Export`

---

## Назначение

Отчёты DTEK Core помогают передать результат работы платформы за пределы интерфейса: руководителю, аудитору, пилотной команде клиента или внутренней рабочей группе.

В Sprint 10 доступны три артефакта:

| Артефакт | Формат | Для чего используется |
|---|---|---|
| Trust Passport report | Print / Save as PDF | Передать состояние конкретного объекта |
| Risk Registry export | CSV | Выгрузить реестр рисков для анализа или согласования |
| Executive Organization Report | Print / Save as PDF | Показать CISO-сводку по организации |

PDF-отчёты реализованы как защищённые печатные страницы. Чтобы получить PDF-файл, откройте отчёт и используйте кнопку **Сохранить PDF** или системный диалог печати браузера.

## Доступ По Ролям

| Отчёт | Владелец | Аналитик ИБ | Администратор | Наблюдатель |
|---|:---:|:---:|:---:|:---:|
| Trust Passport report | ✅ | ✅ | ✅ | ✅ |
| Risk Registry CSV | ✅ | ✅ | ❌ | ❌ |
| Executive Organization Report | ✅ | ✅ | ❌ | ❌ |

Примечания:

- Данные отчётов всегда ограничены текущей организацией пользователя.
- Пользователь не выбирает `organization_id` вручную.
- Export-события фиксируются в журнале аудита безопасности.
- Если отчёт недоступен, платформа показывает безопасное сообщение без технических деталей.

## Trust Passport Report

### Что Содержит

Trust Passport report описывает состояние одного объекта:

- название, тип, критичность и технические атрибуты;
- текущий Trust Score и уровень доверия;
- факторную оценку по 6 факторам;
- открытые связанные риски;
- дату генерации;
- Source / Evidence Coverage placeholder.

### Как Открыть

1. Перейдите в **Объекты** (`/objects`).
2. Откройте нужный объект.
3. Перейдите в **Trust Passport**.
4. Нажмите кнопку **PDF**.
5. На странице отчёта нажмите **Сохранить PDF**.

### Когда Использовать

- для обсуждения состояния критического сервера или приложения;
- как приложение к remediation-плану;
- как артефакт для внутреннего аудита;
- для демонстрации влияния рисков на конкретный актив.

### Ограничения

- PDF создаётся через browser print/save as PDF.
- Если объект удалён, архивирован без доступного паспорта или недоступен текущей роли, будет показано состояние «Отчёт недоступен».
- Отчёт не раскрывает данные других организаций.

## Risk Registry CSV Export

### Что Содержит

CSV export включает текущий набор рисков с учётом активных фильтров:

- Risk ID;
- название и описание;
- категория;
- критичность;
- вероятность;
- CVSS;
- статус;
- impact;
- due date;
- owner и author;
- связанные объекты;
- служебные source/evidence поля для будущей Evidence-first модели.

### Как Скачать

1. Перейдите в **Риски** (`/risks`).
2. При необходимости примените фильтры по поиску, критичности или статусу.
3. Нажмите **CSV**.
4. Браузер скачает файл `dtek-core-risk-registry-YYYY-MM-DD.csv`.

### Как Открывать CSV

Файл экспортируется в UTF-8 с BOM, поэтому должен корректно открываться в Excel, LibreOffice и Google Sheets.

Если файл открывается с неправильной кодировкой:

1. Импортируйте CSV вручную через мастер импорта таблиц.
2. Выберите кодировку UTF-8.
3. Используйте разделитель comma.

### Пустой Экспорт

Если по выбранным фильтрам рисков нет, CSV всё равно будет сформирован. В файле останется строка заголовков без строк данных. Это нормальное поведение.

### Ошибки

Если export временно недоступен, платформа вернёт безопасное сообщение:

```text
Не удалось сформировать CSV-отчёт. Попробуйте повторить экспорт позже.
```

Внутренние технические ошибки пользователю не показываются.

## Executive Organization Report

### Что Содержит

Executive Organization Report — управленческая сводка для CISO:

- Organization Trust Score;
- ключевые KPI организации;
- Executive Summary;
- распределение объектов по уровню доверия;
- факторный профиль организации;
- топ рисковых объектов;
- критические открытые риски;
- Source / Evidence Coverage placeholder.

### Как Открыть

1. Перейдите в **Dashboard** (`/dashboard`).
2. Нажмите **Отчёт CISO**.
3. Проверьте сводку.
4. Нажмите **Сохранить PDF**.

### Когда Использовать

- для еженедельной или ежемесячной CISO-сводки;
- для pilot review с клиентом;
- для демонстрации динамики доверия руководству;
- как управленческий артефакт после инвентаризации объектов и рисков.

### Пустая Цифровая Модель

Если в организации ещё нет активных объектов, отчёт покажет состояние:

```text
Цифровая модель пока пуста
```

Это означает, что отчёт доступен, но для аналитических разделов пока нет данных. Добавьте объекты и риски, затем откройте отчёт повторно.

## Журнал Аудита

Отчёты и экспорт фиксируются в **Настройки → Журнал аудита**:

| Событие | Когда появляется |
|---|---|
| `report.passport_exported` | Пользователь нажал «Сохранить PDF» в Trust Passport report |
| `report.risks_csv_exported` | Пользователь скачал Risk Registry CSV |
| `report.executive_opened` | Пользователь открыл Executive Organization Report |
| `report.executive_exported` | Пользователь нажал «Сохранить PDF» в Executive Report |

Журнал аудита доступен владельцу и администратору организации.

## Безопасность

Отчёты DTEK Core следуют тем же правилам безопасности, что и основной интерфейс:

- report data загружается только server-side;
- доступ проверяется по текущему пользователю и роли;
- данные другой организации не могут попасть в отчёт;
- export endpoints не принимают произвольный `organization_id`;
- audit failure не должен блокировать основной сценарий;
- пользователь не видит внутренние ошибки приложения.

## Ограничения Sprint 10

В текущей версии не реализованы:

- серверная генерация бинарного PDF;
- scheduled reports;
- email delivery;
- report designer;
- кастомный branding отчётов;
- автоматическое вложение evidence-файлов.

Эти возможности могут быть рассмотрены после pilot validation, если они окажутся важны для коммерческого MVP.

## Рекомендуемый Рабочий Процесс

1. Заполните цифровую модель: объекты, критичность, владельцы, технические атрибуты.
2. Зарегистрируйте и привяжите риски.
3. Проверьте Dashboard и Trust Score.
4. Для объекта сформируйте Trust Passport report.
5. Для работы с рисками выгрузите Risk Registry CSV.
6. Для CISO или пилота сформируйте Executive Organization Report.
7. Проверьте журнал аудита, если нужно подтвердить факт экспорта.
