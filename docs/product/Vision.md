# Vision.md — DTEK Core

`Статус: актуальный`  
`Дата: 08.07.2026`

---

## Видение

DTEK Core должен стать Evidence-first Trust Intelligence Platform, через которую руководители ИБ и команды безопасности видят цифровое доверие организации как управляемую систему.

Организация должна понимать не только список активов и рисков, а взаимосвязь:

```text
Evidence -> Активы -> Паспорта доверия -> Риски -> Trust Score -> Управленческие решения
```

---

## Проблема

Во многих организациях данные безопасности разрознены:

- активы живут в CMDB или Excel;
- риски ведутся в таблицах;
- уязвимости находятся в сканерах;
- события лежат в SIEM;
- доступы управляются отдельно;
- отчёты для руководства собираются вручную.

В результате CISO часто видит много сигналов, но не единую картину доверия:

- какие объекты критичны;
- какие объекты сейчас наиболее опасны;
- какие риски сильнее всего влияют на безопасность;
- какие связи могут усилить последствия компрометации;
- как объяснить состояние безопасности бизнесу.

---

## Решение

DTEK Core создаёт единую модель цифрового доверия организации:

- цифровые доказательства показывают происхождение данных;
- каждый объект получает Trust Passport;
- Trust Score показывает уровень доверия;
- Trust Graph показывает связи и зависимости;
- Risk Registry объясняет, что снижает доверие;
- Dashboard переводит техническое состояние в управленческую картину.

Пользователь не должен вручную строить всю инфраструктурную модель. Он подключает источники данных или загружает выгрузки, а платформа обнаруживает, нормализует и предлагает изменения для подтверждения.

---

## Долгосрочная Цель

Сделать DTEK Core стандартным Trust Intelligence layer для управления доверием к цифровым активам в российских организациях среднего и крупного размера.

---

## Принцип Развития

DTEK Core не должен становиться очередным техническим сенсором.

Платформа должна оставаться:

- понятной для CISO;
- полезной для аналитика ИБ;
- быстрой во внедрении;
- совместимой с существующими инструментами;
- evidence-backed;
- достаточно безопасной для работы с чувствительной инфраструктурной информацией.
