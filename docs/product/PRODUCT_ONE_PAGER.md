## DTEK Core

**Платформа управления цифровым доверием и киберрисками активов.**

DTEK Core помогает CISO и командам ИБ быстро понять:

- какие активы организации существуют;
- каким активам можно доверять;
- какие риски сильнее всего снижают доверие;
- как связаны критичные объекты;
- что исправлять первым;
- как объяснить состояние безопасности руководству.

---

## Проблема

Во многих организациях активы, риски и отчётность живут отдельно:

- активы ведутся в Excel, CMDB, Service Desk или разрозненных списках;
- риски фиксируются в Jira, Confluence, GRC, письмах или таблицах;
- связи между системами известны отдельным специалистам, но не видны руководству;
- отчёт для CISO и бизнеса собирается вручную;
- приоритизация часто строится на severity риска, а не на влиянии на критичные активы.

В результате CISO сложно быстро ответить на вопрос:

> Где у нас реально низкое доверие и что нужно исправить первым?

---

## Решение

DTEK Core создаёт управленческий слой над активами, рисками и связями организации.

Платформа объединяет четыре ключевых элемента:

| Элемент | Что даёт |
|---|---|
| Trust Passport | Цифровой паспорт доверия каждого объекта |
| Trust Score | Понятная оценка доверия 0–100 по факторам безопасности |
| Trust Graph | Карта связей между активами и зависимостями |
| Risk Registry | Реестр рисков, связанных с конкретными объектами |

Вместо набора разрозненных таблиц команда получает единую картину:

```text
Организация -> объекты -> риски -> Trust Score -> Trust Graph -> executive insight
```

## Для Кого

### Primary ICP

- российские компании 100–2000 сотрудников;
- есть CISO, руководитель ИБ или IT-директор;
- есть 50–200 важных или критичных активов;
- активы и риски сейчас ведутся вручную или в нескольких системах;
- нужно быстро готовить понятную картину для руководства;
- нет зрелой enterprise GRC/CAASM-платформы.

### First Adopters

- ИТ/SaaS-компании;
- промышленные предприятия среднего размера;
- энергетика и инфраструктурные компании вне тяжёлого enterprise;
- медицинские и образовательные организации;
- ИБ-интеграторы и консалтинг.

## Value Proposition

- единый Trust Score организации;
- топ проблемных активов и рисков;
- понятный executive snapshot для руководства;
- аргументированная приоритизация действий.

### Для Аналитика ИБ

- единый реестр объектов и рисков;
- цифровой паспорт каждого актива;
- связь риска с Trust Score;
- история изменения доверия.

### Для IT-Администратора

- понятный список активов, требующих внимания;
- контекст, почему ИБ просит изменение;
- видимость зависимостей между системами.

### Для ИБ-Интегратора

- repeatable-процесс обследования клиента;
- быстрый trust/risk snapshot;
- управленческий отчёт по итогам пилота.

## Почему Это Отличается От SIEM, EDR, CMDB И GRC

DTEK Core не заменяет существующие средства защиты и учёта.

| Категория | Роль | Чем отличается DTEK Core |
|---|---|---|
| SIEM | Собирает события | DTEK Core показывает управленческое доверие к активам |
| EDR/XDR | Защищает endpoints | DTEK Core связывает риски, активы и бизнес-критичность |
| Сканер уязвимостей | Находит technical findings | DTEK Core помогает понять приоритет по влиянию на доверие |
| CMDB | Хранит inventory | DTEK Core добавляет Trust Passport, риски, score и graph |
| GRC | Управляет контролями и compliance | DTEK Core легче и ближе к asset/risk snapshot для CISO |

Позиционирование:

> Evidence-first Trust Intelligence Platform.

## Ключевой Сценарий

За 10–15 минут демонстрации CISO видит:

1. общий Trust Score организации;
2. топ активов с низким доверием;
3. почему конкретный актив получил такой score;
4. какие риски сильнее всего влияют на доверие;
5. как риск распространяется через связи между объектами;
6. какие действия стоит обсуждать первыми.

---

## 14-Дневный Pilot Offer

Первое рыночное предложение:

> За 14 дней собрать цифровую карту доверия 50–200 ключевых активов, показать Trust Score организации и топ-10 рисков, сильнее всего влияющих на безопасность.

### Входные Данные

- список активов;
- список рисков;
- критичность объектов;
- владельцы или ответственные команды;
- связи между ключевыми системами;
- текущие факторы доверия, если доступны.

### Что Получает Клиент

- демо-организацию с реальными или обезличенными данными;
- Trust Passport для ключевых объектов;
- Trust Score по активам и организации;
- Risk Registry с привязкой к объектам;
- Trust Graph критичных зависимостей;
- итоговую управленческую картину для CISO;
- список топ-10 приоритетов.

### Критерии Успеха Пилота

Пилот считается успешным, если за 14 дней команда клиента может:

- увидеть 50–200 активов в единой модели;
- понять, какие 10 рисков наиболее значимы;
- объяснить руководству, где доверие низкое;
- определить первые действия по снижению риска;
- подтвердить, что формат полезен для регулярной работы.

## Что Не Входит В Первый MVP

На ближайшем этапе DTEK Core не обещает:

- замену SIEM/EDR/DLP;
- автоматическое сканирование инфраструктуры;
- тяжёлую GRC-функциональность;
- on-prem deployment без отдельного решения;
- кастомные роли;
- десятки интеграций с первого дня;
- сертификацию enterprise-уровня до подтверждения Market MVP.
