# DTEK Core Demo Import

Готовый обезличенный набор для наполнения тестовой организации данными из
утверждённой спецификации `docs/product/DEMO_DATASET_SPEC.md`.

## Файлы

| Файл | Содержимое | Ожидаемый preview |
|---|---|---|
| `dtek-core-demo-objects.csv` | 15 объектов IT/OT инфраструктуры | 15 valid, 15 creatable |
| `dtek-core-demo-risks.csv` | 12 рисков по всем основным категориям | 12 valid, 12 creatable |

## Порядок Импорта

1. Войдите как `owner` или `analyst`.
2. Откройте `/objects` и нажмите **Импорт**.
3. Выберите `dtek-core-demo-objects.csv`.
4. Проверьте preview и подтвердите создание 15 объектов.
5. Откройте `/risks` и нажмите **Импорт**.
6. Выберите `dtek-core-demo-risks.csv`.
7. Проверьте preview и подтвердите создание 12 рисков.
8. Откройте Dashboard, Objects, Trust Passport и Risks для проверки данных.

Source metadata уже находятся в каждой строке, поэтому поля источника в диалоге
можно оставить со значениями по умолчанию.

## Ограничения MVP

- Risk CSV связывает один риск только с одним основным объектом.
- Владелец объекта или риска не назначается автоматически из CSV.
- Связи Trust Graph из Demo Dataset создаются отдельно через UI.
- Повторный импорт тех же файлов не обновляет записи: preview покажет дубли и
  `К созданию: 0`.

Используйте набор в тестовой или демонстрационной организации. Файлы не содержат
реальных клиентских данных, публичных IP-адресов, внутренних UUID или секретов.
