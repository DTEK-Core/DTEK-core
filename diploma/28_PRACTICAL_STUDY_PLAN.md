## Неделя 1. Продукт

Прочитать 00–05; открыть README/Product Concept; нарисовать цепочку ценности; объяснить продукт за 2 минуты. Безопасная практика: улучшить собственный конспект, не код.

## Неделя 2. Web и frontend

Прочитать 01, 07, 08; запустить `npm run dev`; пройти routes; найти page/layout/client component. Практика: локально изменить текст в отдельной ветке и посмотреть diff, затем не коммитить без задачи.

## Неделя 3. Backend и БД

Прочитать 09–11; проследить object form → action → migration → passport trigger. Выполнить type-check. Объяснить primary/foreign key, constraint, transaction и migration.

## Неделя 4. Trust core

Прочитать 12–15; пройти `calculate.ts` по шагам; вручную посчитать учебный weighted score; открыть Passport и Graph. Выполнить explainability tests.

## Неделя 5. Evidence и безопасность

Прочитать 16–19; запустить import tests; сравнить source block и target Evidence Layer; составить STRIDE для import; объяснить two-tenant test.

## Неделя 6. Процесс и защита

Прочитать 20–27; выполнить полный pre-demo baseline; провести demo без ИИ; ответить на 20 случайных вопросов; записать слабые места и повторить их.
